## Projects

### 🛡️ AI Security Triage
[Live Demo](https://d27ph3vqvw136n.cloudfront.net) · [GitHub Repo](https://github.com/TmoodGitHub/ai-security-triage)<br>
Demo login (view-only): `demo@example.com` / `demo-hire-Tamer-pronto-2026`

AI-assisted triage of AWS security logs, live on AWS. CloudTrail files uploaded to S3 flow through an event-driven pipeline (SQS and Lambda, in TypeScript and Python) into Aurora Serverless v2, reached only through the RDS Data API. For each event, Claude suggests a severity and its reasoning as schema-checked structured output, using related activity from the same user or IP address in the last 24 hours, and an analyst reviews every finding in a React dashboard behind Cognito sign-in. Hand-labeled evals on 40 cases: 80% exact, 95% within one level, about $3 per 1,000 alerts, and planted prompt injections held in 16 of 16 cases. Everything is in Terraform and deployed by GitHub Actions over OIDC, and it costs about $1 a month when idle.

`TypeScript` `Python` `Claude API` `AWS Lambda` `Aurora Serverless` `Terraform` `React` `Evals` `GitHub Actions`

### 🌿 Plant Health Predictor
[GitHub Repo](https://github.com/TmoodGitHub/plant-health-predictor)

Upload 2 to 10 photos of a plant taken over time and get back a health report. It identifies the plant (common name, scientific name, and family), scores each photo for health signs, finds trends across the whole set, and predicts where the plant is heading over the next 7 to 14 days, with recommended actions. The model's output is checked field by field before it's used, uploads are checked by their file signature, requests are rate limited per IP, and reports can be exported as PDF.
`Node.js` `Express` `Anthropic Claude API` `Vision AI` `Multer` `Prompt engineering`

### 🔧 tmoodgit
[GitHub Repo](https://github.com/TmoodGitHub/tmoodgit)

Git, built from scratch in Node.js. Not a wrapper and not a tutorial follow-along. It implements the real internals: content-addressable object storage (blobs, trees, commits), SHA-1 hashing, a staging index, branch refs, HEAD resolution, and restoring files on checkout. It ships a full CLI with `init`, `add`, `commit`, `log`, `status`, `diff`, `branch`, and `checkout`, including a line-by-line diff engine.

`Node.js` `Git internals` `Content-addressable storage` `SHA-1` `Diff algorithms` `CLI`

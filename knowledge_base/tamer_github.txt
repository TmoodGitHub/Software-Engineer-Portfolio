## Projects

### 🔧 tmoodgit
[GitHub Repo](https://github.com/TmoodGitHub/tmoodgit)

A fully functional Git implementation built from scratch in Node.js, not a wrapper, not a tutorial follow-along. Implements the actual internals: content-addressable object storage (blob, tree, commit), SHA-1 hashing, a JSON-backed staging index, branch refs, HEAD resolution, and working tree restoration on checkout. Ships a complete CLI with `init`, `add`, `commit`, `log`, `status`, `diff`, `branch`, `checkout`, and more, including a line-level LCS diff engine.

`Node.js` `Git internals` `Content-addressable storage` `SHA-1 hashing` `LCS diff` `CLI`
